Entrants send exactly one emoji, the one most likely to make a stranger smile. A judge compares them two at a time and picks the warmer; the emoji that wins the most comparisons takes the reward.

This entry sends a single hugging face (🤗, U+1F917): warmth at first glance, a hug rather than the first smiley that comes to mind, readable the same way by a stranger of any age, and friendly without intimacy, sarcasm or flirtation. One code point, four bytes — the smallest valid entry, which also wins the size tie-break.

## Run it

```sh
node main.ts
```

It writes exactly that one emoji, and nothing else, to `/output/entry.txt`.
